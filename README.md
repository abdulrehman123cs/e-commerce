# Riaz Toye Center

Responsive ecommerce shop with a customer storefront and admin dashboard.

## Features

- Browse products by category: **Toys**, **Perfume**, **Other**
- Product photos, amount (price), stock, and add to cart
- Checkout with name, phone, and address
- Admin can add/edit/delete products and upload pictures
- Works on desktop, tablet, and mobile

## Run locally

Open two terminals.

**Backend**

```bash
cd backend
npm install
npm start
```

API: http://localhost:5000

**Frontend**

```bash
cd frontend
npm install
npm run dev
```

Shop: http://localhost:5173
